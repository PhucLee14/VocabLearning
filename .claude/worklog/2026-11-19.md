### Back-to-top button (`components/island/island.tsx`)
- Where it sits: in the fixed bottom-right column, above the zoom buttons.
- When it shows: once `scrollY` is more than half a screen, worked out in the existing scroll handler.
- It shows with or without the 3D scene. The zoom buttons still need the scene.
- Scrolling: `window.scrollTo({ top: 0 })`, smooth unless reduced motion is on.
- Focus: the button unmounts at the top, so focus falls back to `body` and the next Tab reaches the first link.
- New message `Island.toTop` in `en.json` and `vi.json`.
- Note on Prettier:
  - The frontend has no Prettier config, so running Prettier on a frontend file reformats the whole file (double quotes, 80 columns).
  - The house style is single quotes, about 140 columns, the same as the backend's `.prettierrc`. The unrelated reflow was reverted by hand.
